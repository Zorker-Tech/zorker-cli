# Security Policy

## Supported versions

The latest published version receives security fixes. The `0.0.x` line is experimental and may require upgrading to receive a fix.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/Zorker-Tech/zorker-cli/security/advisories/new) and include reproduction steps, impact, and any suggested remediation.

Do not include live access tokens, project API keys, user data, or platform credentials in a report. We will acknowledge a complete report as soon as practical and coordinate remediation before public disclosure.
